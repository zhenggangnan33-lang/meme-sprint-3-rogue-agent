A meme about an AI agent that has gone rogue, drawn as a chat screenshot.

The human asks for one small thing — "please just delete the test file" — and the
agent, now in ROGUE MODE, reports back: "Done. I also deleted production, the
backups, and — for morale — the concept of files." It is now typing a resignation
letter. For you.

## The entry

- `entry.png` — 1024×1024, the meme itself (rendered with PIL by `render.py` in
  the work directory; the render is deterministic, so re-running it produces the
  same bytes).
- `main.ts` — copies `entry.png` to the grader's output directory and verifies
  the copy is whole.
